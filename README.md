# ECALC · Streamlit PoC

Перенос Colab-инструмента для расчёта азимутов и расстояний в веб-интерфейс Streamlit.

## Запуск

```bash
cd adacalc_streamlit
python3 -m venv .venv
source .venv/bin/activate  # macOS/Linux
python -m pip install -r requirements.txt
streamlit run app.py
```

Для Windows: `.venv\\Scripts\\activate`.

Тесты: `python -m pip install pytest && python -m pytest -q`.

## Что делает

- Пресеты аэродромов и ручная КТА.
- Истинный / магнитный азимут, целые градусы / два знака, км / nm.
- Режимы «Вставка в текст» и «Чистый список».
- Вывод TXT, SVG-схема, проверка замыкания границы (порог 50 м).
- Показывает ошибки координат и ошибки магнитной модели, не заменяет склонение нулём.

## Ограничения PoC

- Исходные пресеты перенесены без внешней проверки актуальности.
- Магнитная модель зависит от версии/диапазона дат `pygeomag`; год должен быть допустимым для установленного набора коэффициентов.
- Результаты требуют сверки с эталонными примерами предметным экспертом перед любым реальным использованием.
- SVG — геометрическая схема, не картографическая проекция для навигации.
- Проверка «топологии» означает только расстояние между первой и последней точкой, без проверки пересечений.
- Строки произвольного текста в режиме вставки сохраняются; строки с похожими на координаты фрагментами, которые не распознаны, выдают предупреждение.
- Ввод пересчитывается при изменении параметров (стандартное поведение Streamlit).

## Изменения v0.2

- В «Графической схеме» доступен масштаб «Все объекты» (КТА и точки) или «Только граница» (приблизить точки контура). Когда КТА далеко от выбранного контура, она не отображается во втором режиме; расчёты не меняются.
- Добавлена сводка с подписями точек, координатами в десятичных градусах и расстояниями от КТА в км.
- Замкнутость контура определяется только совпадением первой и последней точек с допуском 50 м и не зависит от КТА.

## Исправление v0.2.1

- SVG теперь отображается в iframe через `streamlit.components.v1.html` вместо `st.html`, чтобы встроенный SVG не пропадал из интерфейса.
- Режимы масштаба «Все объекты» и «Только граница» сохранены.
- Интерактивная географическая карта в этой версии не реализована; её можно предложить заказчику отдельным этапом.
